# Meal Plan – Downloads

Android app for planning the week's meals: recipes, a shopping list built from the plan, and a pantry that knows what is already at home.

All versions and what changed: [Releases](https://github.com/PantaLolXD/meal-plan-shoping-release/releases)

## Install

1. Open the download link on your Android phone and open the downloaded `meal-plan.apk`.
2. Android asks to allow installing apps from your browser: allow it.
   On Samsung, temporarily turn off *Settings → Security and privacy → Auto Blocker*.
   If Play Protect warns about an unknown app, choose "Install anyway".
3. On first start, choose how to use the app:
   - **Standalone** – everything stays on the phone. No account, no server. Add recipes with *＋ Import* on the Recipes tab.
   - **With a home server** – enter your household server's address (for example `http://10.8.0.1:3000`), then sign in; everyone shares one plan, list and pantry.

   You can change this later in *Settings* (⚙ on the Recipes tab). The two keep separate data – switching does not move anything across.

## Updates

The app checks for a new version every time it starts and offers the download.
Installing the new APK over the old one keeps your recipes, plan and pantry.

In standalone mode your data exists only on this phone, and uninstalling the app deletes it.
To be safe, use *Settings → Save backup* before updating, and keep the file somewhere other than the phone.
*Settings → Restore from backup* puts it back.
